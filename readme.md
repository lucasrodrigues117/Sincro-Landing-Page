# Sincro Landing Page

Landing page do Sincro, uma experiência acadêmica que conecta alunos e professores em torno de turmas, atividades, prazos e desempenho.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Validação

```bash
npm run lint
npm run build
```

## Publicação

O deploy é feito automaticamente no GitHub Pages pelo workflow em `.github/workflows/deploy-pages.yml` sempre que a branch `main` recebe uma atualização.

[Abrir a landing page](https://lucasrodrigues117.github.io/Sincro-Landing-Page/)
